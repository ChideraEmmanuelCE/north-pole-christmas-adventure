# NORTH POLE — The Christmas Mission

A mobile-first 3D Christmas adventure built with Next.js, Three.js, React Three Fiber and Rapier.

## Prototype includes
- Procedural snowy North Pole village
- Santa character placeholder
- Snowy cabins, pine trees and night sky
- Mission HUD and Christmas readiness panel
- Responsive iPhone-friendly layout and capped rendering pixel ratio

## Requirements
Node.js 20.9+ and npm 10+.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
```

## Roadmap
1. Third-person movement and mobile joystick
2. Interactive toy factory and toy crafting
3. Reindeer care and sleigh preparation
4. Sleigh flight and gift-delivery missions
5. World locations, weather, audio and save progression

The current commit is an initial 3D environment prototype, not a finished game.
